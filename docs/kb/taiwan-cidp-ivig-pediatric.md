# 健保：CIDP 病童國血 IVIG（2026-10-01 生效）

- 來源：聯合報 2026-10-07 https://udn.com/news/story/7266/9800492
- 依健保署 9/15 公告：CIDP 診斷與處方醫師擴增為「神經科專科醫師或兒童神經科醫師」；2 歲以上、未滿 18 歲新增國血製劑「益康」IVIG 10%（Privigen TW）；仍需事前審查。
- 國內兒童／青少年 CIDP 每年新增約數十例、總數不超過百人。

## 可重用知識
- CIDP 一線：類固醇、IVIG、血漿置換；病程 >8 週、對稱近端＋遠端無力、反射消失。
- 國血國用可降低進口血漿製劑斷貨風險。
- 限制：給付細則與劑量上限以健保署原文為準。
