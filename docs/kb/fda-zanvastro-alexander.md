# Zanvastro（zilganersen）與亞歷山大病

- 主題：GFAP、反義寡核苷酸、罕見白質腦病
- 種子週：2026-W38
- 來源：FDA，2026-09-03，<https://www.fda.gov/news-events/press-announcements/fda-approves-first-drug-treat-alexander-disease>；NDA 220210 核准信，<https://www.accessdata.fda.gov/drugsatfda_docs/appletter/2026/220210Orig1s000ltr.pdf>

## 可重用重點

- 亞歷山大病：GFAP 突變 → 異常蛋白在星狀膠質細胞堆積；盛行率 <1／百萬。
- Zanvastro 是 ASO，減少異常 GFAP 生成；每 3 個月椎管內注射。
- 首個核准、直接針對病因的療法；適應症涵蓋小兒與成人。
- 樞紐試驗 NCT04849741（n=49，≥2 歲）＋未滿 2 歲開放標籤 4 人；步行速度／動作評估優於未治療。
- 常見 AE：嘔吐、背痛、咳嗽、頭痛、腰椎穿刺後症候群；有無菌性腦膜炎報告。

## 限制

- 極罕見病、樣本小；嬰幼兒適應症部分靠 PK 外推。
- 台灣尚未見同步藥證／給付訊息。
