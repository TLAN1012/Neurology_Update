# 知識前線：NEJM Review 革蘭氏陰性菌抗藥性

- NEJM Review 2026-10-29, DOI 10.1056/NEJMra2506114
- 機轉：進入減少、外排、標的修飾、β-lactamase
- 病原：ESBL、CRE、DTR-PA、CRAB
- 處置：快速診斷、新 β-lactam 針對性使用、源頭控制、療程審慎

## 評讀摘要
- 主張：革蘭氏陰性菌抗藥性在全球快速擴散，由人、環境與醫療相關因素交互驅動，並經可移動遺傳元素加速散播；處置需要及時精準的診斷、針對性使用新一代 β-lactam 類、確實的感染源控制與審慎的療程長度。
- 台灣：台灣 CRE 中以 KPC 為主、但 OXA-48 與 NDM（金屬 β-lactamase）近年上升，選藥時差異很大：KPC 可用 ceftazidime-avibactam、meropenem-vaborbactam；NDM 須 ceftazidime-avibactam＋aztreonam 或 cefiderocol。對神經科與長照：①長期臥床、導尿管、氣切、反覆住院的神經疾病長者是 CRE／CRAB 帶菌高風險族群；②吸入性肺炎與泌尿道感染經驗性治療要參考院內抗生素圖譜與先前培養；③療程不宜過長（多數 7 天即可，依感染部位與源頭控制而定）；④護理之家的接觸隔離與手部衛生是長期防線。

## 可重用知識
- 台灣 CRE：KPC 為主，OXA-48／NDM 上升，選藥不同。
- 臥床神經疾病長者是抗藥菌高風險族群。
