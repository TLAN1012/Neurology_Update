# 加讀：NEJM 高齡者社會需求的測量偏誤

- DOI 10.1056/NEJMp2608580（NEJM 2026-10-15）
- HRSN 工具未針對高齡者驗證；忽略功能、認知、代答與居住情境。
- 建議：年齡與功能敏感、情境化、連結介入。

## 評讀摘要
- 主張：住房不穩、糧食不安全、交通等社會需求（HRSN）篩檢近十年快速導入醫療院所，但多數工具並非為高齡者設計或驗證；「一體適用」的問卷忽略認知與身體功能差異、需要代答者的情況，以及護理之家等居住型態。
- 台灣：台灣的 ICOPE 長者功能評估與長照評估量表同樣面臨「失智者自答準確性」與「照顧者代答偏誤」的問題；本週 JAGS 的 CommunityRx-Dementia 試驗正是「篩出需求後如何接到資源」的實證嘗試。
