# 加讀：NEJM AAV 基因治療後插入致瘤

- DOI 10.1056/NEJMc2607927（NEJM 2026-10-15）
- Krabbe 病童 FBX-101（AAVrh.10, CAG-GALC, 3e13 vg/kg）後 26 個月 L2–L3 GLI1 改變腫瘤。
- 1,038 bp 載體子片段（CMV/CBA 啟動子＋剪接供體，無 GALC）插入 GLI1 intron 1 → 嵌合轉錄本。
- 建議：避免剪接供體、載體純度、延長基因體監測。

## 評讀摘要
- 主張：AAV 載體以「不整合」為主、在數千名受試者中有良好安全紀錄，但本例證明 AAV 整合可直接導致腫瘤，且是繼 Ahrens-Nicklas 等報告 PLAG1 活化腫瘤後的又一例。
- 台灣：台灣是 AAV 基因治療的重要發源地之一（AADC 缺乏症的腦內 AAV2 基因治療由台大團隊推動），國內也有 SMA 病童接受 onasemnogene。本例提醒：基因治療後的長期追蹤不只看療效，也要有影像與腫瘤監測計畫；與家屬溝通時可說明風險極低但非零。

## 可重用知識
- AAV 整合致瘤第二例（前例 PLAG1）。
- 基因治療後需長期影像／腫瘤監測。
