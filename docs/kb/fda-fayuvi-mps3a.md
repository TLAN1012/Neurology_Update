# Fayuvi（rebisufligene etisparvovec）與 MPS IIIA

- 主題：溶小體儲積症、AAV9 基因治療、兒童神經退化
- 種子週：2026-W38
- 來源：FDA，2026-09-17，<https://www.fda.gov/news-events/press-announcements/fda-approves-first-gene-therapy-pediatric-patients-sanfilippo-syndrome-type>；Reuters，2026-09-17，<https://www.reuters.com/business/healthcare-pharmaceuticals/us-fda-approves-ultragenyxs-gene-therapy-rare-disorder-2026-09-17/>

## 可重用重點

- Sanfilippo A 型＝MPS IIIA：SGSH 缺陷 → 硫酸乙醯肝素堆積 → 認知／語言／動作倒退。
- Fayuvi：AAV9 單次靜脈輸注，補上正常 SGSH；適應症限神經發育功能仍保留的兒童。
- 2–5 歲開放標籤試驗相對歷史對照：認知維持或進步。
- 需輸注前一天起、至少八週類固醇；風險含肝酶上升、血球減少、TMA，以及 AAV 插入致癌的理論風險。
- Reuters：美國目錄價 395 萬美元；30–60 天內於專責中心供藥。

## 限制

- 歷史對照、非同期隨機，效應估計較脆。
- 「功能仍保留」意味時間窗很窄：確診太晚可能不符合。
- 超高價與中心化給藥，可近性是政策問題，不只是科學問題。
