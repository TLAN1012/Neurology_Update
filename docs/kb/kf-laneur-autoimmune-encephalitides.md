# 知識前線：Lancet Neurology 抗體介導腦炎綜述

- DOI 10.1016/S1474-4422(26)00290-5（Lancet Neurol 2026-11, 25(11):1039–1052）；Comment 10.1016/S1474-4422(26)00373-X
- 主張：自體免疫腦炎應依抗體視為不同疾病，而非單一症候群。
- 例：NMDAR、LGI1、IgLON5——族群、誘因、機轉、表現、預後、治療皆不同；需跨科照護。
- 選刊：Lancet 正刊本週無神經 feature，改選 Lancet Neurology。

## 評讀摘要
- 主張：抗體介導的膠質細胞與神經元疾病，已把許多過去被視為「特發性」或未被認為與免疫相關的神經疾病改寫為可診斷、可治療。針對 aquaporin-4 與 MOG 的疾病已被視為各自獨立的疾病實體；但針對神經元抗原的自體免疫腦炎仍常被「打包」分析，彷彿同一疾病——作者主張應改以抗體定義的個別疾病來看待。
- 台灣：這三種病在神經科門診都可能以「看似失智、精神病或難治癲癇」出現：年長者亞急性記憶退化＋頻繁短暫面臂抽動＋低血鈉要想到 LGI1；夜間異常行為、喘鳴、吞嚥困難伴認知變化要想到 IgLON5（可與知識庫中快速進展失智（RPD）相關筆記並讀）。實務上建議血清與腦脊髓液同時以 cell-based assay 檢測（NMDAR 以 CSF 較敏感），國內多數需送醫學中心；疑似時不宜等待結果才開始免疫治療。

## 可重用知識
- LGI1：年長男性、FBDS、低血鈉；IgLON5：睡眠異常、延腦症狀、tau 病理。
- 血清＋CSF cell-based assay；勿延誤免疫治療。
