# 太平洋紫杉醇過敏與蓖麻油溶劑

- 主題：化療藥安、輸液反應、賦形劑
- 種子週：2026-W38
- 來源：中央社，2026-09-06，<https://www.cna.com.tw/news/ahel/202609060109.aspx>

## 可重用重點

- 傳統 paclitaxel 需聚氧乙烯蓖麻油（Cremophor EL）助溶；過敏常來自賦形劑，不一定是紫杉醇本體。
- 台灣至 2026-04-18 有 28 件嚴重過敏通報，皆為含蓖麻油溶劑製劑；食藥署將要求中文仿單增修警語與預防用藥資訊。
- 臨床常規：輸液前類固醇／抗組織胺、床邊急救、不要用「上次沒事」推論永遠安全。
- 白蛋白結合型等劑型避開蓖麻油，但適應症與給付不同，不能自動替換。
