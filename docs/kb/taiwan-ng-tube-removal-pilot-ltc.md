# 健保署住宿型機構鼻胃管移除試辦：約 9% 病人留置逾 3 個月，三項獎勵拚及早移除

- 2026-11-23 石崇良：鼻胃管約 9% 留置逾 3 個月，多在居家／住宿型機構
- 114 年約 28 萬人放鼻胃管，9 成短期
- 健保 2026-09-01 起 2,020 萬元試辦：開辦 3 萬、照護 8,000＋1 萬、品質 5～6 萬元

## 可重用知識
- 晚期失智不建議以管灌取代小心手餵（careful hand feeding）。
- 移除評估要分辨可復能的吞嚥障礙與疾病末期進食困難；後者應走 ACP／安寧。
