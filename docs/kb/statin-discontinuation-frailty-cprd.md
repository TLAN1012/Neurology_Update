# 長者停用 statin 的風險依衰弱程度遞減（英國 CPRD）

- Lancet Healthy Longev 2026, DOI 10.1016/j.lanhl.2026.100920
- 65,727 停藥 vs 131,453 繼續
- 1 年住院 sHR 1.22；健康 1.30 → 嚴重衰弱 1.03、失智 1.05、機構 0.76
- 觀察性、殘餘干擾
