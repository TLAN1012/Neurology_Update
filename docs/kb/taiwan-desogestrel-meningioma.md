# Desogestrel／etonogestrel 避孕藥與腦膜瘤再評估

- 來源：Focus Taiwan / CNA，2026-09-21
- URL：https://focustaiwan.tw/society/202609210007

## 要點
- TFDA 跟進 EMA：長期（≥1 年）使用與顱內腦膜瘤小幅風險上升相關。
- 絕對風險低（EMA：約每 67,300 人多 1 例）；既往腦膜瘤為禁忌方向。
- 台灣 6+2 項許可證；十年內尚無相關通報（截至 2026-07-14）。

## 臨床備忘
- 神經科新診斷腦膜瘤女性：詢問長效黃體素／避孕史，協同婦產科評估停換藥。
- 症狀警訊：視力、聽力／耳鳴、嗅覺、頭痛惡化、癲癇、肢體無力。

## 限制
- 再評估結果未定；無通報 ≠ 零風險。
