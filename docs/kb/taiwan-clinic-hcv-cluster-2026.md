# 新北診所營養針 C 肝群聚（2026）與注射安全

- 來源：中央社 2026-10-12 https://www.cna.com.tw/news/ahel/202610120183.aspx
- 22 例確診；1,118 人回溯篩檢（陽性率約 3%）；9 例序列相似度 99.7–100%。
- 初步報告：組織、監督、感管與人員督導系統性問題；醫療法第 18 條負責醫師督導責任；正式報告預計 11 月底。

## 診所自我檢核
- 單劑量包裝優先；一人一針一管；多劑量瓶不可重複以用過針具抽取。
- 配藥區與汙染區分離、手部衛生、定期稽核與教育訓練紀錄。
- 自費點滴／營養針／醫美注射屬高風險流程。
