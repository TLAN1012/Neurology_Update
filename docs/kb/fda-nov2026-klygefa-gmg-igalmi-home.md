# FDA：gefurulimab（Klygefa）用於 AChR 抗體陽性 gMG；舌下 dexmedetomidine（Igalmi）居家使用

- 2026-11-16 FDA 核准 Klygefa（gefurulimab）：AChR+ gMG，每週皮下
- PREVAIL n=260：MG-ADL −1.6
- Igalmi 舌下 dexmedetomidine 擴大居家使用（SERENITY III）
- Igalmi 不適用於失智激躁；注意低血壓

## 可重用知識
- gMG 補體抑制劑需腦膜炎雙球菌疫苗。
- 失智激躁不在 Igalmi 適應症內。
