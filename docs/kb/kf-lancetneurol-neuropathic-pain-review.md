# 加讀：Lancet Neurology Review——神經病變性疼痛的診斷、機轉與治療進展（附 JAMA 帶狀疱疹後神經痛）

- Lancet Neurol Review 2026-11-18（Vollert、Baron）：神經病變性疼痛
- JAMA Insights 2026-11-23：帶狀疱疹後神經痛

## 評讀摘要
- 主張：神經病變性疼痛是體感覺神經系統病灶或疾病造成的慢性疼痛，與傷害感受性疼痛不同；病人間與疾病間機轉差異大，未來要靠辨識並針對個人機轉來提升療效，疾病修飾治療才能擺脫純症狀處理。
- 台灣：台灣高齡糖尿病與帶狀疱疹病人多，基層常見；長者使用 gabapentinoid 或三環抗憂鬱劑時要注意嗜睡、跌倒與抗膽鹼負擔（失智風險）。帶狀疱疹疫苗（重組型）可降低帶狀疱疹與後神經痛風險，CTAD 2026 也有帶狀疱疹疫苗與失智的自然實驗研究報告，可一併衛教。

## 可重用知識
- 神經病變性疼痛＝體感覺神經系統病灶所致；機轉分層是未來方向。
- 長者用 gabapentinoid／TCA 注意跌倒與抗膽鹼負擔。
