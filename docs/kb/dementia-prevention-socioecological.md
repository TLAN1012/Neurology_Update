# 失智預防的社會生態觀點

- 主題：可調整因子、公共衛生、長照與都市計畫
- 種子週：2026-W38
- 來源：Dunne 等，*The Lancet Public Health*，2026-09-09，<https://www.thelancet.com/journals/lanpub/article/PIIS2468-2667(26)00171-4/fulltext>

## 可重用重點

- 把文獻中 61 個可調整失智因子對到個人／人際／社區／社會四層。
- 80% 落在個人層；上游證據明顯不足，不是上游不重要。
- 有效預防需要教育、都市計畫、環境政策與醫療協同。
- 台灣可對照：長照據點、1966、年輕型失智納入長照、空污與交通設計。

## 限制

- Viewpoint，映射既有 PAF 文獻，不是新的因果試驗。
- 不能直接輸出一套台灣人口可歸因分數。
