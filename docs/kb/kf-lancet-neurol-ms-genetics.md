# 加讀：Lancet Neurology MS 遺傳學的臨床意義

- Lancet Neurol 2026, DOI 10.1016/S1474-4422(26)00356-X
- GWAS 數百位點、免疫為主
- 易感性≠嚴重度／進展
- 目前用途：機轉、標靶、因果、標記、研究世代

## 評讀摘要
- 主張：GWAS 已找到數百個 MS 風險位點，多涉及免疫路徑，解釋了免疫調節藥為何抑制復發；但易感性遺傳無法解釋失能累積、病程差異與治療反應。
- 台灣：與上方 REMODEL 並讀：BTK 抑制劑等新藥瞄準的正是易感性遺傳無法解釋的「進展」層面。台灣 MS 少、NMOSD 相對多，歐洲 GWAS 結果不宜直接套用。

## 可重用知識
- MS 遺傳學尚無個人化臨床工具。
- 亞洲族群資料不足。
