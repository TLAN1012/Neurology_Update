# 知識前線：Neurology COL4A1/2 小血管病入門

- DOI 10.1212/WNL.0000000000218628（Neurology Review；線上 2026-10-16；2026-11-10 期）
- 主張：COL4A1/2 SVD 被低估；出血＋缺血雙表型；跨年齡。
- 證據：微出血、WMH、腔隙、EPVS；眼／腎／肌肉紅旗；抗血栓個別化、動脈瘤監測；多代案例。
- 限制：敘事性綜述、罕病證據等級低。

## 評讀摘要
- 主張：COL4A1/2 編碼基底膜的第 IV 型膠原蛋白，致病變異造成以腦血管為主的多系統小血管病變；隨基因檢測普及，此病仍嚴重低估，主因是表型異質性極大——從無症狀、偶然影像發現，到反覆缺血、腦出血，乃至災難性的周產期腦損傷，且可發生在任何年齡。作者提供以機轉為基礎、臨床可操作的辨識與處置框架。
- 台灣：評讀者補充：在台灣，最常被想到的單基因小血管病是 CADASIL（NOTCH3，國內 R544C 變異特別常見）；但遇到年輕或家族性腦出血、腦穿通畸形（porencephaly）／周產期腦出血病史、視網膜小動脈迂曲、合併腎病或肌肉痙攣、廣泛微出血卻無高血壓的病人，應把 COL4A1/2 納入基因套組。對診所的實際影響：抗血小板或抗凝前評估微出血負荷；建議家族篩檢與遺傳諮詢；避免把年輕腦出血一律歸因於「高血壓」或「血管畸形」。

## 可重用知識
- 台灣：CADASIL（NOTCH3 R544C）之外，年輕／家族性 ICH、porencephaly、視網膜動脈迂曲時想到 COL4A1/2。
- 抗血栓前評估微出血；遺傳諮詢。
