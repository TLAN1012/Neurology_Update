# GLP-1 受體促效劑 NAION 警語：FDA 全類加註、食藥署啟動再評估、台灣首例藥害救濟

- FDA 2026-11-09：全類 GLP-1 加註 NAION 警語
- 食藥署 2026-11-11：啟動全類再評估；今年 ADR 63 件（減重 39 件）
- 台灣首例 GLP-1 眼部藥害救濟（Ozempic 適應症外減重）審議中
- 糖尿病學會：減重劑量較高，應以代謝科為中心

## 可重用知識
- NAION：單眼無痛視力下降、視盤水腫；與視網膜動脈阻塞（眼中風）要區分。
- 擁擠視盤、對側 NAION、OSA 為高風險族群。
