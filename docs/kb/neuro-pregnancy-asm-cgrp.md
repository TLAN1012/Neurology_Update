# 育齡女性神經科用藥：酵素誘導 ASM×避孕、抗 CGRP×自然流產

- Neurology 線上 2026-10-07 DOI 10.1212/WNL.0000000000218679：21,923 名使用易受影響避孕者中 32.6% 與酵素誘導 ASM 重疊 ≥14 天（中位 218 天）；智能障礙 aOR 2.33、難治型 1.73、>35 歲 1.45。
- JAMA Neurol 線上 2026-10-12 DOI 10.1001/jamaneurol.2026.3573：早期懷孕抗 CGRP 單抗 aHR 1.42（1.12–1.80）；propranolol aHR 1.02。
- 不受酵素誘導影響：銅 IUD、LNG-IUD、DMPA。
- 抗 CGRP 單抗半衰期長：計畫懷孕前提早停藥並討論避孕。
