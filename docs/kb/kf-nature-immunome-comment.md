# 加讀：Nature Comment——量測免疫健康能否重塑醫療

- Nature Comment 2026-10-27, DOI 10.1038/d41586-026-03396-2
- 免疫生物年齡與神經退化、癌症、死亡相關
- immunome 組件：蛋白／抗體、單細胞、受體定序、影像、空間、挑戰反應

## 評讀摘要
- 主張：同齡者的免疫系統差異極大，免疫的「生物年齡」已和神經退化、癌症與死亡風險相關；臨床卻沒有常規方式評估整體免疫健康，作者呼籲建立跨細胞、組織、器官與分子交互的「immunome」。
- 台灣：對老年醫學：「免疫老化」與衰弱、疫苗反應、譫妄與失智風險相關（本週健康幣疫苗新聞即是群體層面的介入）。短期內可用的仍是疫苗史、感染史與基本發炎指標；immunome 屬研究方向。

## 可重用知識
- 免疫老化連結衰弱、疫苗反應與神經退化。
- 屬研究方向，尚無臨床工具。
