# 加讀：Lancet Healthy Longevity Review——2026 年針對老化標誌的藥物管線

- Lancet HL Review 2026-11-23：193 個試驗、131 種療法
- 21% 針對健康／高風險者，79% 針對老年疾病；一二期占 79%

## 評讀摘要
- 主張：雖然許多進行中的試驗瞄準被視為「老化標誌」的生物機轉，但多數仍在早期階段，而且主要是治療特定老年疾病，而非延緩或預防與年齡相關的功能衰退本身。
- 台灣：病人常問 metformin、NAD+ 前驅物、rapamycin、senolytics 能否「抗老」：本篇顯示多數仍在一、二期，針對健康人的試驗只占兩成，目前沒有任何藥物被核准用於延緩老化。門診可把重點放回已證實有效的運動、血壓、聽力、社交與疫苗；CTAD 2026 也有間歇性 rapamycin 用於早期阿茲海默症的研究報告。

## 可重用知識
- 目前沒有藥物被核准用於延緩老化；多數 geroscience 試驗在早期。
