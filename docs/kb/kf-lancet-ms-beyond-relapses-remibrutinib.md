# 知識前線：Lancet 社論——多發性硬化症：超越控制復發（附 remibrutinib REMODEL 試驗與評論）

- Lancet 社論 2026-11-19／21：MS 超越控制復發；首段：>20 種 DMT、>300 萬人
- REMODEL-1/-2 2,007 人：remibrutinib vs teriflunomide ARR RR 0.648／0.688
- tolebrutinib 2025-12 FDA CRL（肝損傷、效益不明）

## 評讀摘要
- 主張：（首段原文要旨＋依標題推論）很少有神經疾病像多發性硬化症（MS）這樣在診斷與治療上經歷劇變：三十年前幾乎無藥可用，如今已有超過 20 種疾病修飾療法。但多數藥物主要壓制「復發」與 MRI 新病灶；病人長期失能更多來自「與復發無關的進展」（PIRA）與慢性神經退化。下一階段的目標應是真正減緩失能累積，而能穿透中樞、同時作用於 B 細胞與骨髓細胞（小膠質細胞）的 BTK 抑制劑，被寄望能處理這部分。
- 台灣：①台灣 MS 盛行率低，病人多由醫學中心追蹤，已有多種疾病修飾藥可用（給付條件依健保規定，本頁未逐一核對）；remibrutinib 在台灣尚無 MS 適應症（Rhapsido 目前在美、歐、日、中核准用於蕁麻疹），短期不會改變門診；②基層與一般神經科的角色在於「早期辨識與轉介」：年輕人視神經炎、脊髓症狀、複視時，應安排 MRI 並轉介（W46 2024 McDonald 準則已把視神經納入病灶部位）；③對已穩定多年的中年病人，開始談「失能進展而非復發」的追蹤指標（步行速度、手部功能、認知處理速度），這與使用者門診的步態量測工具可以結合。

## 可重用知識
- PIRA＝與復發無關的失能進展；是 MS 長期失能主因。
- BTK 抑制劑同時作用 B 細胞與小膠質細胞，被寄望處理進展。
