# 加讀：Nature——UNC13A 剪接校正 ASO 挽救 TDP-43 流失造成的突觸功能障礙

- Nature 2026-11-11（Keuss…Fratta）
- TDP-43 流失→突觸傳遞崩壞（退化前）
- UNC13A 剪接校正 ASO 恢復突觸釋放與網路同步
- 理論適用約 97% ALS、50% TDP-43 FTD

## 評讀摘要
- 主張：TDP-43 自細胞核流失（ALS 與 FTD 的病理標誌）會在神經元結構仍完整時，先造成突觸傳遞大幅崩壞的「退化前狀態」；只要校正 UNC13A 單一隱性外顯子（cryptic exon）剪接錯誤，就足以挽救此缺陷。
- 台灣：台灣 ALS 病人可經恩慈或臨床試驗接觸 ASO 療法（tofersen 僅適用 SOD1 突變，約 2%）；UNC13A 策略若成功，將是第一個可適用於多數散發性 ALS 的基因層級治療。臨床上也提醒：FTD-ALS 譜系病人應考慮基因檢測（C9orf72、TARDBP 等），以便日後參加試驗。

## 可重用知識
- UNC13A 隱性外顯子是 TDP-43 病理的關鍵下游標的。
