# 加讀：Lancet Neurology 神經創傷慢性病化

- DOI 10.1016/S1474-4422(26)00297-8；Editorial 10.1016/S1474-4422(26)00367-4
- TBI/SCI >2.2 億人；應重分類為急性起病的多系統慢性風險疾病。
- 特有風險：創傷後垂體低下、自律神經失調、加速老化、認知行為障礙。

## 評讀摘要
- 主張：TBI 與 SCI 影響全球逾 2.2 億人，傷後數年至數十年伴隨心血管代謝、內分泌、神經與精神後遺症；多數醫療體系仍把神經創傷當成一次性事件，導致長期監測破碎或缺席、可預防的死亡與再住院。成人 TBI 與 SCI 應重新歸類為「急性起病的多系統慢性風險疾病」。
- 台灣：台灣機車事故相關 TBI 負擔高，急性期救治成熟，但出院後的長期追蹤（垂體功能、癲癇、認知、情緒）多半散落各科。神經科門診遇到「多年前頭部外傷」的病人，出現疲倦、性功能或體重改變時，別忘了檢查垂體功能；也可與 W42 清大 TBI 候選化合物筆記並讀。

## 可重用知識
- 門診：舊外傷＋疲倦／體重／性功能變化 → 查垂體。
