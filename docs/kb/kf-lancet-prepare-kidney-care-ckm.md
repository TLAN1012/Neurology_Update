# 知識前線：Lancet Prepare for Kidney Care（保守腎臟照護 vs 透析準備）與 Comment

- Lancet RCT 2026-11-04 + Comment 2026-11-06
- n=445（篩檢 6,120），中位 82 歲，追蹤 4.5 年
- QALY 1.354 vs 1.472，差 −0.147（CI −0.350 至 0.056）
- 通路併發症 IRR 0.41；死亡 69% vs 63%

## 評讀摘要
- 主張：（RCT 與 Comment 標題所示）對 ≥80 歲、或 65–79 歲合併衰弱／多重共病的腎衰竭長者，以「準備透析」為預設路徑並不比以症狀控制與生活品質為核心的「回應式保守照護（protocolised conservative kidney management）」帶來更多 QALY；Comment 的問句點出：為一個可能永遠不會開始的透析做準備（廔管手術、衛教）本身就有代價。
- 台灣：台灣透析盛行率全球最高之一，高齡透析比例高，「安寧緩和腎臟照護」與健保「末期腎臟病前期（Pre-ESRD）」計畫已有基礎，但保守照護選項常未被充分討論。對神經與老年科的連結：①中重度失智、多次中風、帕金森晚期合併腎衰竭的長者，透析常伴隨譫妄、跌倒、功能下滑，共享決策時可引用本試驗：在 QALY 上兩者無顯著差異、保守照護少了通路手術併發症；②決策應納入病人價值（延長存活 vs 居家時間）、預立醫療照護諮商（ACP）與病主法；③腎科、老年科、安寧團隊與家庭醫師共同參與。

## 可重用知識
- 高齡衰弱腎衰竭：保守照護是正當選項，需共享決策。
- 無顯著差異≠等效。
