# 老福法第22條修法：65歲以上有條件免健保費爭議

- 中央社 2026-10-20／10-24；立法院 10/16 三讀
- 綜所稅率<20% 或未達申報標準之 65+ 由中央全額補助健保費；刪除地方補助部分負擔／未給付醫療費
- 石崇良：約 8 成長者符合；被刪部分社會救助法無法替代
- 陳時中：偏離量能付費、未修財劃法，籲修回

## 可重用知識
- 政策重點常在「被刪的條文」：地方對部分負擔的補助法源消失。
- 超高齡社會下，以年齡＋所得稅率排富會涵蓋多數長者。
