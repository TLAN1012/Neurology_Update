# 加讀：A&D Perspective——睡眠評估應納入記憶門診

- Alz Dement 2026, DOI 10.1002/alz.71880
- 記憶門診缺乏系統性睡眠評估
- 提出 stepped-care 框架

## 評讀摘要
- 主張：失眠、睡眠呼吸中止、晝夜節律失調與 RBD 都與認知下降、神經退化病理與生活品質相關，但多數記憶門診沒有系統性評估；作者比較四個國際情境並提出階梯式照護框架。
- 台灣：台灣記憶門診可低成本導入：STOP-Bang、RBD 單題問卷（RBD1Q）、失眠嚴重度量表，並把鎮靜安眠藥減量納入；睡眠檢查等候時間長，可先用居家睡眠呼吸檢測分流。

## 可重用知識
- STOP-Bang、RBD1Q、ISI 可快速篩檢。
- 與 p-tau217 解讀（OSA）相關。
