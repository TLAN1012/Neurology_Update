# 知識前線（替代）：Lancet REMODEL-1/2 remibrutinib 治療復發型 MS

- Lancet 2026-10-23, DOI 10.1016/S0140-6736(26)02058-1（替代：原著）
- 2,007 人；remibrutinib 100 mg BID vs teriflunomide
- ARR RR 0.648／0.688
- 停藥 3.1% vs 5.8%；無肝安全疑慮（摘要）

## 評讀摘要
- 主張：高選擇性、共價、可入腦的口服 BTK 抑制劑 remibrutinib 在復發型 MS 降低年化復發率優於 teriflunomide，且安全性良好、無肝臟安全疑慮。
- 台灣：台灣 MS 盛行率低，且視神經脊髓炎（NMOSD）比例相對高，使用 BTK 抑制劑前須先以 AQP4、MOG 抗體排除 NMOSD／MOGAD（部分 MS 藥物會使 NMOSD 惡化）。若未來引進，口服且免監測肝功能的特性可能有吸引力，但給付定位會以第一線中效藥替代為討論起點。

## 可重用知識
- BTK 抑制劑：B 細胞＋小膠質細胞，目標 PIRA。
- 台灣：先排除 NMOSD／MOGAD。
