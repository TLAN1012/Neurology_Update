# ARO-MAPT：皮下 siRNA 降 tau

- 來源：Arrowhead 2026-10-14；NCT07221344
- CSF 總 tau 第 105 天：2.1 mg/kg −40%、6.4 mg/kg −69%（D1/8/15）、12.8 mg/kg −73%（D1/15；最大 −85%）。
- 安全：無 SAE、無停藥；常見注射部位反應。早期 AD 資料 2027。

## 可重用知識
- 皮下 siRNA 穿越 BBB（TRiM）——若屬實可取代鞘內 ASO（如 BIIB080）。
- 限制：健康受試者、生物標記、新聞稿。
