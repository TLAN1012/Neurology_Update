# 加碼：NEJM ASPIRED——急診不明原因暈厥立即 14 天心電圖監測

- NEJM 2026-10-29 期, DOI 10.1056/NEJMoa2605812
- 2,234 人；1 年暈厥 1.37 vs 1.58（IRR 0.89，NS）
- 社論 Probst 10.1056/NEJMe2612346

## 評讀摘要
- 主張：急診評估後仍不明原因的暈厥，立即 14 天動態心電圖監測並未顯著減少病人自述的 1 年暈厥次數。
- 台灣：暈厥常轉介神經科做腦波或影像，但多數是反射性或心因性；暈厥與癲癇的鑑別重點（誘因、前驅症狀、發作時間、意識恢復速度、舌咬傷位置）仍是門診核心。本研究提醒：監測工具可提升診斷，但未必改變結果。
